# Office Inventory and Dispatch Management System

## Overview
A web-based Office Inventory and Dispatch Management System developed to automate inventory management, purchase order generation, dispatch tracking, stock monitoring, and requirement approval workflows.

## Features
- Inventory Management
- Purchase Order Generation
- Dispatch Tracking
- Stock Monitoring
- Requirement Approval Workflow
- Excel Import & Export
- Advanced Search & Filtering
- WhatsApp Integration
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## Installation

```bash
npm install
npm start
```
